# Classic Paint for Mac · 0.2

Swift + AppKit 原生离线画图应用。界面与操作方向以 Windows 7 经典画图为准；macOS 13+，Apple Silicon。

## 使用与构建

这是可绘图、编辑和保存的开发版。仓库提供源码；请在 Apple Silicon Mac 上安装 Xcode Command Line Tools 后构建：

```sh
git clone https://github.com/windysoul126/ClassicPaint.git
cd ClassicPaint
zsh scripts/build-app.sh
.build/ClassicPaint --self-test
```

构建完成后，打开 `dist/Classic Paint 0.2.app`。

构建只依赖 macOS Command Line Tools 和系统 AppKit、Core Graphics、ImageIO。运行时不需要登录、联网或下载资源。

## 当前功能

- 新建、打开、保存、另存为、打印；PNG / JPEG / BMP / TIFF / GIF（单帧）。保存采用原子写入。
- 铅笔、九种画笔模式、橡皮擦、取色、封闭区域填充、放大镜。左键颜色 1，右键颜色 2；橡皮擦用颜色 2 擦除，右键可替换颜色 1。
- 23 种形状入口，包括直线、两次弯曲的曲线、多边形、箭头、星形、标注、心形和闪电；轮廓、填充、粗细与材质设置。
- 矩形 / 自由图形选择、移动、右下角缩放、复制 / 剪切 / 粘贴、粘贴自文件、删除、透明选择；支持拖入图片。
- 裁剪、按像素或百分比缩放、保持比例、扭曲、90° / 180°旋转、翻转、反色、画布尺寸、黑白转换。
- 画布文字编辑框；字体、字号、粗体、斜体、下划线、透明 / 不透明背景、中文文字。文字提交后成为图像像素。
- 撤销 / 重做、未保存提醒、25%–800% 缩放、400% 以上像素网格、标尺、状态栏、全屏、缩略图。
- 经典色板、颜色 1 / 颜色 2、自定义颜色。
- 工具专用光标；画笔和橡皮擦轮廓随粗细及缩放变化。

## 操作提示

- `⌘N / O / S`：新建 / 打开 / 保存；`⇧⌘S`：另存为；`⌘P`：打印。
- `⌘Z / ⇧⌘Z`：撤销 / 重做；`⌘X / C / V / A`：剪切 / 复制 / 粘贴 / 全选。
- 选择、画笔、粘贴的大按钮下方箭头打开菜单。
- `Shift` 绘制约束线条角度或形状比例；多边形双击完成；曲线画出初始线后再拖动两次弯曲。
- `Enter` 完成曲线 / 多边形；`Esc` 取消进行中的操作。选区可用方向键移动，`Shift` 加快。
- 画布右下角小方块可改变画布大小；精确尺寸可用“文件 → 图像属性”。

## 验证和边界

自动检查：64 项，覆盖像素坐标、填充、选区掩膜、变换、撤销与保存状态、文件往返、形状绘制、材质差异。包含工具光标尺寸与切换检查；运行上方测试命令可查看结果。

真实 UI 已检查：矩形、填充、撤销重做、中文文字提交、选区移动、PNG 保存并重新打开、比例缩放及尺寸撤销、缩放 / 网格 / 标尺。验证图片和本机检查记录不包含在源码仓库中。

当前仍是开发版，不能称为 Windows 7 画图的逐像素完整复刻：

- 图标为本地矢量绘制 / 系统符号，天然画笔和材质是近似算法，尚未与 Windows 7 实机逐像素对照。
- 普通形状松开鼠标即栅格化；尚未实现原版形状提交前的全部调整行为。选区目前只有右下角缩放柄。
- 图像属性采用像素单位；Windows 专属扫描仪、发送邮件、设为壁纸入口未移植。
- 打印已接入 macOS 打印面板，尚未做纸张输出验证。macOS 13 是编译目标，未在该版本系统上实机回归。
- 图像限制：单边最大 16384 像素、总像素最多 2400 万；撤销最多 50 步，历史约 160 MB 上限（至少保留一步）。
- 应用为本地临时签名，尚未做 Developer ID 分发签名和公证。
